Accessibility-træet i Chrome

Denne side er lavet til fælles inspektion. Se først på siden, forudsig derefter træet, og åbn så DevTools.

Sådan inspicerer I i Chrome
  1. Åbn DevTools og vælg fanen Elements.
  2. Markér det element, I undersøger.
  3. Åbn panelet Accessibility. Find det eventuelt via DevTools-menuen eller kommandoen “Show Accessibility”.
  4. Notér elementets role, name, description og eventuelle properties.
  5. Udløs ændringen på siden, og inspicér elementet igen.
